# ⏱️ Task 27 – Pomodoro Timer

A futuristic and responsive **Pomodoro Timer** built using HTML5, CSS3, and JavaScript.

This project helps users manage focused work sessions and break sessions using the Pomodoro productivity technique.

## 🚀 Live Demo

🔗 https://silambarasanc199-jpg.github.io/task-27-pomodoro-timer/

## ✨ Features

- ⏱️ Work Timer
- ☕ Break Timer
- ▶️ Start Timer
- ⏸️ Pause Timer
- 🔄 Reset Timer
- 🔁 Automatic Work & Break Switching
- ⚙️ Custom Work Duration
- ⚙️ Custom Break Duration
- 📊 Completed Session Counter
- 🎯 Focus Minutes Tracker
- 🔢 Cycle Counter
- ⌨️ Keyboard Shortcuts
- 📱 Fully Responsive Design
- 🌙 Futuristic Dark UI

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Start / Pause |
| `R` | Reset Timer |
